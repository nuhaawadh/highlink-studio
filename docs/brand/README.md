# هوية هاي لينك

ضعي هنا ملفات الهوية (Brand Identity + DLS): الشعار بصيغة SVG، لوحة الألوان بقيم HEX/RGB، الخطوط، وقواعد المسافات.

ثم تُكتب القيم في `apps/web/src/styles/tokens.css` فقط (المتغيرات `--col-*` و`--font-*`). لا تُعدَّل المكوّنات لتغيير الألوان.

المطلوب كحد أدنى:
- `--col-brand` لون البراند الأساسي (وعليه `--col-brand-ink` لون النص فوقه)
- `--col-bg` / `--col-surface` / `--col-border` للثيم الداكن
- اسم الخط العربي والخط اللاتيني (Google Fonts أو ملفات محلية في `apps/web/public/fonts/`)
