تُولَّد فيديوهات وصور الديمو من المنصة نفسها في المرحلة 2 (اختبار القبول الحقيقي).
لكل مقطع: البرومبت، النموذج، 3 محاولات، الأفضل يُرفع إلى Cloudflare Stream ويُسجَّل هنا كـ `demo.json`:

```json
{ "key": "hero", "model": "kling-v3-turbo", "prompt": "…", "stream_uid": "…", "chosen_of": 3, "credits_spent": 78 }
```

قواعد: لا علامات تجارية حقيقية، كل الشخصيات مولّدة، كل مقطع يُحفظ مع برومبته ليصير منشورًا في مدوّنة البرومبتات.
